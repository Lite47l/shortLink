# shortLink

**shortLink** — это высокопроизводительный сервис для сокращения URL-адресов, написанный на языке Go. Проект реализует чистую архитектуру, поддерживает переключаемые хранилища (in-memory и PostgreSQL) и готов к развертыванию в контейнерах.

## Особенности

- **Гибкое хранилище**: Поддержка как in-memory хранилища (для быстрого старта и тестирования), так и PostgreSQL (для продакшена) через единый интерфейс.
- **Чистая архитектура**: Разделение ответственности на слои `config`, `handler`, `service` и `storage`.
- **Надежность**: Реализован graceful shutdown для корректного завершения работы сервера и обработки сигналов ОС.
- **Логирование**: Структурированное JSON-логирование с использованием стандартной библиотеки `log/slog`.
- **Контейнеризация**: Полная поддержка Docker и `docker-compose` для быстрого развертывания вместе с базой данных и миграциями.

##  Стек технологий

- **Язык**: Go 1.25
- **База данных**: PostgreSQL (драйвер `github.com/jackc/pgx/v5`)
- **Инфраструктура**: Docker, Docker Compose
- **Архитектура**: Clean Architecture, Dependency Injection
- **Тестирование**: Встроенный фреймворк `testing`

## Структура проекта

```text
.
├── cmd/app/            # Точка входа в приложение (main.go), инициализация зависимостей и graceful shutdown
├── internal/           # Закрытые пакеты приложения
│   ├── config/         # Загрузка и валидация конфигурации из переменных окружения
│   ├── handler/        # HTTP-обработчики (маршрутизация и парсинг запросов/ответов)
│   ├── service/        # Бизнес-логика приложения
│   └── storage/        # Интерфейс хранилища и его реализации (memory, postgres)
├── migrations/         # SQL-миграции для схемы базы данных PostgreSQL
├── .env.example        # Пример файла с переменными окружения
├── docker-compose.yml  # Конфигурация для запуска сервиса и БД
├── Dockerfile          # Инструкции для сборки Docker-образа
├── go.mod / go.sum     # Управление зависимостями Go
└── README.md           # Документация проекта
```

## Запуск проекта
1: Локальный запуск (In-Memory)

```bush
$env:STORAGE_TYPE="memory"
$env:SERVER_PORT="8080"

go run cmd/app/main.go
```

2: Запуск через Docker (с PostgreSQL)

```bush
docker-compose up --build

docker-compose down
```

##  Тестирование

```bush
go test ./... -v

```
